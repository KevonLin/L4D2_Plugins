## Plugins by KevonLin

### 8v8 All-Charger Evolution

- `8v8/l4d2_8v8`: Remove the 4-player limit for both teams; supports 8v8.
- `8v8/l4d2_afk_manager`: Move AFK players to spectators when teams are full.
- `8v8/l4d2_cgs`: Charger Growth System; set unique Charger charge speed per client.
- `8v8/l4d2_spec_queue`: Advanced team queue management system (observer join queue).

### CLVPlus Special

- `clvplus_charger_catch_dmg`: Applies safe instant damage when a Charger grabs a survivor.
- `clvplus_shove_manager`: Control special infected shove behavior.
- `clvplus_tank_rock`: Tank rock health adjustment.
- `clvplus_tankswap`: Tank Swap simplified for CLVPlus.
- `clvplus_uid_system_mysql`: UID system (MySQL version).
- `clvplus_uid_system_sqlite`: UID system (SQLite version).
- `kz_uid_system_sqlite`: UID system for KZ server (SQLite version).

### Others

- `l4d2_auto_change_slots`: Change slots when the server is full (versus only; requires `l4d2_unreserverlobbyafterslots`).
- `l4d2_auto_remove_lobby`: Auto-remove lobby when slots are not 8 or 4.
- `l4d2_blast_dmg`: Explosive damage adjustment against Tank.
- `l4d2_infected_colldown_manager`: Special infected cooldown manager; adjust special infected cooldown/recharge time.
- `l4d2_max_health_fix`: Fix survivor max health exceeding 100.
- `l4d2_mpg`: Admins change max players in-game.
- `l4d2_refusereturnlobby`: Limit player votes to return to lobby.
- `l4d2_saferoom_gnome`: Spawns a gnome in the saferoom.
- `l4d2_tankswap`: Allow the primary Tank player to surrender control to teammates, or admins to take it, with spechud adaptation.
- `l4d2_unreserverlobbyafterslots`: Set server unreserved when slots exceed 8.
- `l4d2_vote`: Vote functions (hp/pills/slots/custom maps/ban/kick/mute).
- `l4d2_votekickimmunity`: Admins cannot be voted off.
- `l4d2_votemenu`: Some useful functions provided for voting (next map/custom maps/matchmodes/ban/kick/mute/toggle addons).
- `l4d2_witch_bonus`: Recover health when a survivor kills a Witch; apply a health penalty when a Tank kills the Witch.
- `l4d_idle_spawn_common`: Spawn commons when a common dies.
- `l4d_modify_for_idle`: Achievement farming panel plugin; modifies server parameters for zombie farming (infinite zombies/special infected, auto fire/aim).
- `l4d_sm_respawn`: Admin respawn/teleport/summon menu.
- `l4d_spec_listener`: Enable spectators to listen to voice chat from other teams.
- `lerpfilter`: Filter players with high lerp.

## Third-party / Collected Plugins

- `bots`: L4D2 Bots; let bots join teams.
- `clvplus_skill_detect`: Skill detect; detect skeet/crown/DP etc. (by Tabun).
- `clvplus_tank_control`: Distribute the Tank role evenly throughout the team (by arti).
- `EntType`: Entity type control, original version.
- `L4D2_Buy_Store`: Human and Zombie Shop; earn credits and buy items (by HarryPoter).
- `l4d2_ent_type`: Entity type control, companion version for prop spawning plugins.
- `l4d2_fix_spawn_order`: Fix special infected spawn order (by Sir).
- `l4d2_jockeyPounce`: Inflicts distance bonus damage to the Jockey's victim if pounced from great height (by N3wton, Visor, JaneDoe).
- `l4d2_melee_range`: Control melee attack range (by Silvers).
- `l4d2_spawn_props`: Prop spawning plugin; spawn/strip props and entities (by honorcode23 & $atanic $pirit & HarryPotter).
- `l4dffannounce`: Add Friendly Fire Announcements (by Frustian).
- `l4d_ffannounce`: Add Friendly Fire Announcements (by Frustian, old version).
- `l4d_shove_handler`: Override the shoving system (by SilverShot).
- `l4d_votes_5`: Vote plugin (by fenghf, Harry Potter).
- `modules`: Confogl modules, e.g. PasswordSystem.
- `profilestatus`: Limits server entry to players by checking Steam Profile Status (by ratawar).
- `readyup`: New and improved ready-up plugin (by CanadaRox, Target).
- `server_namer`: Dynamic server hostname formatter (by sheo, Forgetest).
- `sm_restart_empty`: Restart server when all players leave the game (by Alex Dragokas).
- `spec_exploit_fix`: Fix spectator and special infected exploits (by Dragokas).
